# Speaking Studio

Personal IELTS Speaking practice for Bixing Wu, with English references for Parts 1, 2 and 3, story routes, response phrases and test-day guidance.

Open the website at https://bixingwu.github.io/ielts-speaking-studio/ on a phone or computer.

This is a static website. Additional notes and practice progress are saved separately in each browser; they do not sync between devices. Export a backup from **Your stories** before clearing browser data.

Source PDFs, Word documents and local working files are kept offline. Model wording and practice adaptations are labelled in the website. This is personal preparation material, not an official prediction or a guaranteed band score. No redistribution licence is granted for third-party study material.

Open Sans font files are distributed with their original licence in `OpenSans-LICENSE.txt`.

To publish, select **Settings → Pages → Deploy from a branch → main → / (root)**. The `.nojekyll` file keeps the site buildless.
